# Objetivo de la pŕactica
Conocer acerca de las peculiaridades, similitudes y principalmente, las diferencias que mantienen los lenguajes de programación Haskell y Rust. Esto porque Haskell será el primer lenguje de programación que usaremos para las prácticas de la materia de Estructuras Discretas y es necesario establecer un primer contacto para poder familiarizarnos con él.

También se buscó entender cuáles han sido los factores que han determinado el que un lenguaje de programación puramente funcional ,como lo es Haskell, nunca ha terminado de popularizarse tanto como sí lo han hecho otros lenguajes, por ejeplo: Java, Python, JavaScript, etc.

Y finalmente, reafirmamos el concepto que tenemos sobre Git y cuál es su relación con GitHub, cómo es que se complementan para formar un entorno de trabajo que nos permite trabajar de manera local y posteriormente, compartir con la comunidad nuestros proyectos, invitarlos a colaborar o acceder a el trabajo de otros, todo esto a través de Git Y GitHub.

El tiempo requerido para concluir la práctica fue de aproximadamente 2 horas.

El único inconveniente con el que me enfrenté al momento de instalar Haskell, es que mi laptop no tenía instalado GHCup, el cual es necesario para que Haskell pueda funcionar correctamente. La solución fue simplemente ejecutar el siguiente comando en la terminal: curl --proto '=https' --tlsv1.2 -sSf https://haskell.org | sh
Después de eso, no tuve nungún problema y pude instalar Haskell correctamente.
